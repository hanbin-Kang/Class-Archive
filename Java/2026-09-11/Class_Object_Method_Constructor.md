# Java 복습

## 09/10 — 메소드 사용(호출)

### 1. 메소드 호출의 기본 구조

Java에서 메소드를 호출하려면 먼저 **해당 메소드를 사용할 수 있는 객체가 필요하다.**

```java
class Test {

    public void add() {
        System.out.println("add 실행");
    }
}
```

```java
Test v = new Test();
v.add();
```

### 2. 객체 생성

```java
Test v = new Test();
```

* `new Test()` → `Test` 클래스의 객체를 생성
* `v` → 생성된 객체를 가리키는 **참조변수**
* 생성된 객체를 통해 `add()` 메소드를 호출할 수 있다.

```java
v.add();
```

### 3. 핵심 흐름

```text
클래스
 ↓
new를 이용하여 객체 생성
 ↓
참조변수에 객체의 참조값 저장
 ↓
참조변수를 이용하여 메소드 호출
```

> **주의:** "메소드 자체를 메모리에 올리려면 클래스를 메모리에 올린다"라고 단순하게 이해하기보다는, **일반적인 인스턴스 메소드는 객체를 생성한 후 그 객체를 통해 호출한다**고 이해하는 것이 정확하다.

# 09/11 — Java 기본 구조

## 1. Java에서 생략되는 요소

### (1) `extends Object`

다음 두 코드는 상속 관계를 기준으로 같은 의미를 가진다.

```java
class A {
}
```

```java
class A extends Object {
}
```

Java의 모든 클래스는 명시적으로 다른 클래스를 상속하지 않는 경우 `Object`를 암묵적으로 상속한다.

---

### (2) 기본 생성자(Default Constructor)

클래스에 **생성자를 하나도 작성하지 않으면**, 컴파일러가 매개변수가 없는 기본 생성자를 제공한다.

```java
class A {
}
```

위 코드는 개념적으로 다음과 같은 생성자를 제공받는다.

```java
class A {

    A() {
    }
}
```

따라서 다음과 같이 객체를 생성할 수 있다.

```java
A a = new A();
```

> **주의:** 직접 생성자를 하나라도 작성하면 컴파일러가 기본 생성자를 자동으로 만들어주지 않는다.

# 2. 클래스란?

클래스는 객체를 만들기 위한 설계도 역할을 하며, 내부에는 여러 구성 요소를 작성할 수 있다.

지금 단계에서는 다음 3가지를 중심으로 이해한다.

```text
클래스
 ├── 멤버변수
 ├── 메소드
 └── 생성자
```

---

## (1) 메소드(Method)

특정 작업을 수행하는 코드의 묶음이다.

```java
public void printX() {
    System.out.println(x);
}
```

### `static`

`static`이 붙은 멤버는 **특정 객체에 소속되는 것이 아니라 클래스에 소속**된다.

따라서 객체를 생성하지 않고도 클래스명을 통해 접근할 수 있다.

```java
class Test {

    static int x = 10;

    static void printX() {
        System.out.println(x);
    }
}
```

```java
System.out.println(Test.x);
Test.printX();
```

> `static`은 "프로그램 시작 시 가장 먼저 메모리에 올라간다"라고 단순 암기하기보다, **객체가 아닌 클래스에 소속되어 객체 생성 없이 사용할 수 있다**는 점을 우선 이해한다.

---

# 3. 멤버변수와 지역변수

변수는 **어디에 선언했는지**에 따라 구분할 수 있다.

```java
public class ExtendEx {

    int x = 10; // 멤버변수

    public void printX() {

        int y = 20; // 지역변수
    }
}
```

### 멤버변수

* 클래스 내부에 선언된 변수
* 객체가 생성되면 객체의 상태를 나타내는 변수로 사용됨
* 값을 직접 지정하지 않아도 기본값으로 초기화됨

```java
int x = 10;
```

### 지역변수

* 메소드, 반복문 등의 특정 영역 안에서 선언된 변수
* 선언된 영역 안에서만 사용 가능
* 자동 초기화되지 않음

```java
public void printX() {

    int y = 20;
}
```

### 핵심

> **변수가 어디에 선언되어 있는가?**

이것을 기준으로 멤버변수와 지역변수를 구분한다.

# 4. 생성자(Constructor)

생성자는 객체가 생성될 때 호출되는 특별한 메소드 형태의 구성 요소이다.

### 생성자를 사용하는 가장 큰 목적

> **멤버변수를 초기화하기 위해 사용한다.**

```java
class Person {

    String name;
    int age;

    Person(String n, int a) {
        name = n;
        age = a;
    }
}
```

```java
Person p = new Person("김길동", 20);
```

객체가 생성되면서 생성자가 호출되고,

```text
name → "김길동"
age  → 20
```

으로 초기화된다.

---

## 생성자 특징

### ① 클래스명과 이름이 같음

```java
class Person {

    Person() {
    }
}
```

### ② 리턴형이 없음

```java
Person() {
}
```

`void`도 작성하지 않는다.

### ③ 오버로딩 가능

매개변수의 타입이나 개수가 다르면 여러 생성자를 만들 수 있다.

```java
class Person {

    Person() {
    }

    Person(String name) {
    }

    Person(String name, int age) {
    }
}
```

객체 생성 시 전달한 인자에 맞는 생성자가 선택된다.

```java
Person p1 = new Person();
Person p2 = new Person("김길동");
Person p3 = new Person("김길동", 20);
```

# 전체 흐름

```text
클래스
 │
 ├── 멤버변수
 │     ├── 객체의 데이터
 │     └── 멤버변수 / 지역변수 구분
 │
 ├── 메소드
 │     └── 객체의 기능
 │
 └── 생성자
       └── 객체 생성 시 호출
       └── 멤버변수 초기화에 주로 사용
```

### 지금까지의 핵심

```text
클래스
 ↓
객체 생성 (new)
 ↓
생성자 호출
 ↓
객체의 멤버변수 초기화
 ↓
참조변수로 객체의 메소드 호출
```
