# 2026-09-04 Java 수업 내용

## 1. 반복문

반복문은 **반복되는 코드를 줄이기 위해 사용** 한다.

Java에서 대표적인 반복문은 다음과 같다.

* `for`
* `while`

### for문

같은 코드가 여러 번 반복해서 실행될 때 `for문`을 사용한다.

```java
for (변수 초기화; 조건식; 증감식) {
    반복하여 수행할 코드;
}
```

예:

```java
for (int i = 0; i < 10; i++) {
    System.out.println(i);
}
```

`for문` 안에는 다른 `for문`이나 `if문` 등을 넣을 수도 있다.

```java
for (int i = 0; i < 10; i++) {

    if (i % 2 == 0) {
        System.out.println(i);
    }

}
```

### 반복되는 코드와 함수

반복해서 실행되는 코드를 줄이는 것과 별개로,
**특정 기능을 여러 곳에서 사용해야 한다면 메서드(method)를 만들어 재사용** 할 수 있다.

즉,

* 반복해서 실행 → `for`, `while`
* 특정 기능을 묶어서 재사용 → `method`

`while문`은 이후에 학습할 예정.

# 2. Java를 배우는 이유

Java를 배우는 중요한 이유 중 하나는 **객체지향 프로그래밍(OOP)** 을 지원하기 때문이다.

### OOP

**OOP = Object-Oriented Programming**

객체를 중심으로 프로그램을 설계하는 프로그래밍 방식이다.

Java는 객체지향 프로그래밍을 기반으로 프로그램을 작성한다.

---

# 3. 프로그램은 어떻게 실행되는가?

컴퓨터에서 프로그램을 실행할 때는 저장장치에 있는 프로그램을 바로 CPU가 실행하는 것이 아니다.

```text
SSD
 ↓
메모리(RAM)
 ↓
CPU
```

SSD는 용량은 크지만 RAM보다 상대적으로 느리고,
CPU는 매우 빠르기 때문에 CPU가 SSD에 직접 접근해서 실행하는 방식보다는 **실행에 필요한 데이터를 메모리에 올린 후 CPU가 처리하는 구조** 로 이해하면 된다.

예를 들어 100GB짜리 프로그램이 있다고 해서 실행할 때 100GB 전체를 메모리에 올릴 필요는 없다.

실제로 필요한 코드와 데이터 등을 필요한 시점에 메모리에서 사용할 수 있도록 처리한다.

# 4. Java의 Class와 Object

Java를 이해할 때 중요한 개념이 바로 **Class와 Object** 이다.

## Class

Class는 객체를 만들기 위한 **설계도 또는 틀** 이라고 생각하면 이해하기 쉽다.

예를 들어:

```java
class Test {

}
```

여기서 `Test`라는 Class를 정의한 것이다.

Class 자체가 곧 Object인 것은 아니다.

---

## Object

Class를 기반으로 실제로 생성된 **객체(instance)** 가 Object이다.

예:

```java
class Test {

}

Test t = new Test();
```

여기서:

```java
new Test();
```

를 통해 `Test` Class를 기반으로 실제 객체가 생성된다.

개념적으로 보면:

```text
Class
 Test
  ↓
new Test()
  ↓
Object
```

즉,

> **Class는 객체를 만들기 위한 설계도이고, Object는 그 설계도를 기반으로 실제 생성된 객체이다.**

---

# 5. `new`의 역할

`new`는 **새로운 객체를 생성할 때 사용하는 연산자** 이다.

```java
Test t = new Test();
```

이 코드를 나누어 보면:

```text
Test t
```

→ `Test` 타입의 참조변수 `t`를 선언

```text
new Test()
```

→ `Test` 객체를 새로 생성

```text
Test t = new Test();
```

→ 생성된 객체를 `t`가 참조하도록 한다.

개념적으로 메모리를 단순화해서 표현하면:

```text
t ─────▶ [Test 객체]
```

여기서 중요한 것은 `t`에 객체 자체가 들어가는 것이 아니라,
**객체를 참조할 수 있는 값이 저장된다는 것** 이다.

---

# 6. 참조변수

다음 코드를 보자.

```java
Test t = new Test();
```

여기서 `t`는 일반적인 숫자 값을 저장하는 변수와 조금 다르다.

`Test`는 Class 타입이므로 `t`는 **참조변수(reference variable)** 이다.

개념적으로 보면:

```text
변수 t
 ↓
참조값
 ↓
Test 객체
```

메모리 주소를 단순하게 표현하면:

```text
t ─────▶ 0x100 ─────▶ [Test 객체]
```

따라서 `t`에는 객체 자체가 아니라 **객체를 가리키는 참조값** 이 있다고 이해하면 된다.

---

# 7. Class와 Object 정리

```java
class Test {

}

Test t = new Test();
```

관계를 정리하면:

```text
Class
└── Test
     │
     │ new Test()
     ↓
   Object
     ↑
     │
     t
```

또는 간단하게:

```text
Test Class
    ↓
new Test()
    ↓
Test Object
    ↑
    │
    t
```

### 핵심 정리

* **Class** → 객체를 만들기 위한 설계도
* **Object** → Class를 기반으로 실제 생성된 객체
* **`new`** → 새로운 객체를 생성
* **참조변수** → 객체를 가리키는 참조값을 저장
* `Test t = new Test();` → `Test` 객체를 생성하고 `t`가 해당 객체를 참조

---

# 한 줄 정리

> **Class는 객체를 만들기 위한 설계도이고, `new`를 통해 실제 Object를 생성하며, 참조변수는 생성된 Object를 참조한다.**
