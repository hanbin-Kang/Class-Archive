# 2026-08-28 Java 수업 내용

## 1. 배열

같은 타입의 값을 여러 개 저장할 수 있는 공간

### 배열 선언 및 초기화 방법

**1) 배열 선언과 동시에 초기화**

```java
int[] x = {10, 20, 30};
```

**2) 배열의 크기를 지정한 후 값 저장**

```java
int[] y = new int[3];

y[0] = 10;
y[1] = 20;
y[2] = 30;
```

**3) `new`를 사용하여 초기화**

```java
int[] z = new int[]{10, 20, 30};
```

### 다차원 배열

행마다 열의 크기를 다르게 지정할 수 있다.

```java
int[][] x = new int[3][];
```

→ 각 행의 열 크기를 따로 지정할 수 있음

## 2. 자바에서 `=`의 의미

`=`은 기본자료형과 참조자료형에 따라 다르게 동작한다.

### 기본자료형

기본자료형은 **값 자체를 복사**한다.

```java
int x = 10;
int y = x;

x = 100;
```

결과:

```text
x → 100
y → 10
```

`y = x`를 할 때 `x`의 값인 `10`이 복사되었기 때문에 `x`가 변경되어도 `y`는 변경되지 않는다.

### 참조자료형

참조자료형은 객체를 가리키는 **참조값이 복사**된다.

```java
int[] x = {10, 20, 30};
int[] y = x;

x[0] = 100;
```

결과:

```text
x[0] → 100
y[0] → 100
```

`x`와 `y`가 같은 배열 객체를 참조하고 있기 때문이다.

> **기본자료형 → 값 복사**
> **참조자료형 → 참조값 복사**

## 3. 클래스(Class)

클래스는 **객체를 만들기 위한 설계도 또는 틀**이다.

```java
class Student {
    String name;
    int age;
}
```

`Student` 클래스에는 `name`, `age`라는 **필드**가 정의되어 있다.

```text
Student 클래스
├── name : String
└── age  : int
```

클래스에서 어떤 필드를 가질지 미리 정의하고, 이 클래스를 이용하여 여러 개의 객체를 만들 수 있다.

---

## 4. 객체(Object)

객체는 **클래스를 이용해 실제로 만들어진 것**이다.

```java
Student s = new Student();
```

여기서 `new Student()`를 통해 실제 `Student` 객체가 생성된다.

```text
Student 클래스
    ↓ new
Student 객체
┌──────────────┐
│ name         │
│ age          │
└──────────────┘
```

같은 클래스를 사용하여 여러 개의 객체를 만들 수 있다.

```java
Student s = new Student();
Student a = new Student();
```

```text
s → Student 객체 ①
     ├── name
     └── age

a → Student 객체 ②
     ├── name
     └── age
```

두 객체는 **서로 다른 객체**이지만 같은 `Student` 클래스로 만들어졌기 때문에 같은 필드 구조를 가진다.

단, 각 객체가 가지고 있는 실제 값은 서로 다를 수 있다.

```java
s.name = "한빈";
a.name = "철수";
```

```text
객체 ①             객체 ②
name = "한빈"       name = "철수"
```

> **클래스 → 설계도**
> **객체 → 설계도로 만든 실제 결과물**

## 5. 참조변수

객체를 생성하면 객체를 가리키는 **참조변수**를 사용할 수 있다.

```java
Student s = new Student();
```

여기서:

```text
Student      → 클래스/타입
s            → 참조변수
new Student  → 객체 생성
```

`s`는 Student 객체를 가리키는 참조변수이며, 객체를 참조하기 위한 **참조값**을 가지고 있다.

```text
s ─────→ Student 객체
          ├── name
          └── age
```

따라서 `s.name`은

> `s`가 가리키는 Student 객체의 `name` 필드에 접근한다.

라는 의미이다.

## 6. `new`를 이용한 객체 생성

```java
Student s = new Student();
```

과정을 나누어 보면:

```text
Student
→ 객체를 만들기 위한 클래스/타입

new Student()
→ Student 클래스를 이용하여 새로운 객체 생성

s
→ 생성된 객체를 가리키는 참조변수
```

즉,

> **Student 클래스를 이용해 `new Student()`로 객체를 만들고, `s`가 그 객체를 참조한다.**

## 7. 같은 클래스에서 여러 객체 생성

```java
Student s = new Student();
Student a = new Student();
```

`new Student()`가 두 번 실행되므로 **서로 다른 객체 2개**가 생성된다.

```text
Student 클래스
      │
      ├── new → 객체 ① ← s
      │
      └── new → 객체 ② ← a
```

같은 클래스에서 만들어졌기 때문에 `name`, `age`와 같은 같은 필드 구조를 가지지만, 각각 독립적인 객체이다.

```java
s.name = "한빈";
s.age = 20;

a.name = "철수";
a.age = 30;
```

```text
s → 객체 ①
     ├── name = "한빈"
     └── age = 20

a → 객체 ②
     ├── name = "철수"
     └── age = 30
```

## 8. 참조변수끼리 대입하기

```java
Student s = new Student();
Student a = s;
```

참조자료형에서 `=`을 사용하면 객체 자체를 복사하는 것이 아니라 **참조값을 복사**한다.

따라서 `s`와 `a`는 같은 객체를 가리키게 된다.

```text
s ──┐
    ├──→ Student 객체
a ──┘
```

예를 들어:

```java
s.name = "한빈";
a.name = "철수";
```

두 참조변수가 같은 객체를 가리키고 있기 때문에 최종적으로:

```text
s.name → "철수"
a.name → "철수"
```

가 된다.

## 9. 참조변수의 참조 대상 변경

```java
Student s = new Student();
Student a = new Student();

s.name = "한빈";
a.name = "철수";

a = s;
```

처음에는:

```text
s → 객체 ①
     name = "한빈"

a → 객체 ②
     name = "철수"
```

`a = s`를 실행하면 `a`가 가지고 있던 참조값이 `s`의 참조값으로 변경된다.

```text
s ──┐
    ├──→ 객체 ①
a ──┘     name = "한빈"

객체 ②
name = "철수"
```

따라서:

```text
s.name → "한빈"
a.name → "한빈"
```

객체 ②의 데이터가 `a = s`에 의해 즉시 삭제되는 것은 아니다. 다만 더 이상 참조하는 변수가 없다면 JVM의 Garbage Collector가 해당 객체를 나중에 회수할 수 있다.

## 10. 클래스와 객체의 관계 정리

```text
Student 클래스
    │
    │ new
    ├──────────────→ Student 객체 ① ← s
    │                    ├── name
    │                    └── age
    │
    └──────────────→ Student 객체 ② ← a
                         ├── name
                         └── age
```

> **클래스** → 객체를 만들기 위한 설계도
> **객체** → 클래스를 이용해 실제로 생성된 것
> **필드** → 객체가 가지는 데이터
> **참조변수** → 객체를 가리키는 변수
> **`new`** → 객체를 생성하는 키워드
> **참조값** → 참조변수가 객체를 가리키기 위해 가지고 있는 값

### 핵심 흐름

```text
클래스 정의
   ↓
new를 이용해 객체 생성
   ↓
참조변수가 객체를 가리킴
   ↓
참조변수를 통해 객체의 필드에 접근
```
