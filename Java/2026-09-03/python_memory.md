# Python 변수와 참조값 이해하기

## 1. Python 변수는 객체를 가리킨다

Python에서는 변수에 값을 직접 넣는다고 생각하기보다,
**변수가 객체를 가리킨다**고 이해하는 것이 좋습니다.

예를 들어:

```python
x = 10
```

`10`이라는 객체가 메모리에 존재하고, `x`는 그 객체를 가리킵니다.

```text
x ─────▶ [10]
```

메모리 주소를 단순화해서 표현하면:

```text
x ─────▶ 0x0 ─────▶ [10]
```

즉, `x`는 `10` 객체 자체가 아니라 **10 객체를 가리키는 참조값**을 가지고 있다고 이해할 수 있습니다.

> 실제 Python 구현에서는 메모리 관리와 객체 배치가 더 복잡하지만, 학습을 위해 주소값을 단순화해서 표현합니다.

---

# 2. `y = x`를 하면?

```python
x = 10
y = x
```

이때 `y`는 `x`가 가지고 있던 **참조값을 복사**합니다.

```text
x ─────▶ 0x0 ─────▶ [10]
y ─────▶ 0x0 ─────▶ [10]
```

따라서 `x`와 `y`는 현재 **같은 객체를 가리키고 있습니다.**

```text
x = 0x0
y = 0x0
```

---

# 3. 처음 헷갈렸던 부분

다음 코드를 생각해 봅니다.

```python
x = 10
y = x
x = 30
```

처음에는:

```text
x ─────▶ 0x0 ─────▶ [10]
y ─────▶ 0x0 ─────▶ [10]
```

여기서 `x = 30`을 하면,

```text
x ─────▶ 0x1 ─────▶ [30]
y ─────▶ 0x0 ─────▶ [10]
```

이 됩니다.

따라서:

```python
print(x)  # 30
print(y)  # 10
```

---

# 4. 왜 `y`까지 30이 되지 않을까?

처음에는 다음과 같이 생각할 수 있습니다.

> `x`와 `y`가 같은 주소를 가지고 있으니까
> `x`의 값을 30으로 바꾸면 `y`도 30이 되는 것 아닌가?

하지만 여기서 중요한 것은:

```python
x = 30
```

이 **기존 객체의 값을 변경하는 것이 아니라는 것**입니다.

`x = 30`은 단순히 **x가 가지고 있는 참조값을 새로운 객체의 참조값으로 변경**합니다.

```text
변경 전

x ─────▶ 0x0 ─────▶ [10]
y ─────▶ 0x0 ─────▶ [10]


x = 30 실행

x ─────▶ 0x1 ─────▶ [30]
y ─────▶ 0x0 ─────▶ [10]
```

즉,

```text
x : 0x0 → 0x1
y : 0x0 → 그대로
```

입니다.

---

# 5. `y = x`를 다시 실행하면?

다음과 같이 하면 결과가 달라집니다.

```python
x = 10
y = x
x = 30
y = x
```

실행 과정을 보면:

### ① `x = 10`

```text
x ─────▶ 0x0 ─────▶ [10]
```

### ② `y = x`

```text
x ─────▶ 0x0 ─────▶ [10]
y ─────▶ 0x0 ─────▶ [10]
```

### ③ `x = 30`

```text
x ─────▶ 0x1 ─────▶ [30]
y ─────▶ 0x0 ─────▶ [10]
```

### ④ `y = x`

이 시점에서 `x`가 가지고 있는 참조값은 `0x1`입니다.

따라서 `y`도 `0x1`을 가지게 됩니다.

```text
x ─────▶ 0x1 ─────▶ [30]
y ─────▶ 0x1 ─────▶ [30]
```

결과:

```python
print(x)  # 30
print(y)  # 30
```

---

# 6. 핵심: `y = x`는 그 순간의 참조값을 복사한다

가장 중요한 부분입니다.

```python
y = x
```

는

> **"앞으로 x가 가리키는 곳을 계속 따라간다"**

가 아닙니다.

그 순간 `x`가 가지고 있는 **참조값을 복사하는 것**입니다.

예:

```text
x ─────▶ 0x0
y = x

y ─────▶ 0x0
```

이후 `x`가 바뀌어도:

```text
x ─────▶ 0x1
y ─────▶ 0x0
```

`y`는 여전히 `0x0`을 가지고 있습니다.

---

# 7. 그렇다면 리스트에서는 왜 같이 바뀔까?

리스트처럼 **객체 자체를 변경할 수 있는 자료형(mutable object)**에서는 다른 상황이 발생합니다.

```python
x = [10]
y = x

x.append(30)
```

처음:

```text
x ─────┐
       ├────▶ 0x0 ─────▶ [10]
y ─────┘
```

`x.append(30)`은 `x`의 참조값을 바꾸는 것이 아닙니다.

**0x0에 있는 기존 리스트 객체 자체를 변경합니다.**

```text
x ─────┐
       ├────▶ 0x0 ─────▶ [10, 30]
y ─────┘
```

따라서:

```python
print(x)  # [10, 30]
print(y)  # [10, 30]
```

이 됩니다.

---

# 8. `=`과 객체 변경의 차이

## `x = 30`

**변수가 가리키는 대상을 변경**

```text
x ─────▶ [10]

       ↓ x = 30

x ─────▶ [30]
```

---

## `x.append(30)`

**변수가 가리키는 객체 자체를 변경**

```text
x ─────┐
       ├────▶ [10]
y ─────┘

       ↓ x.append(30)

x ─────┐
       ├────▶ [10, 30]
y ─────┘
```

---

# 9. 최종 정리

Python에서 변수와 객체의 관계는 다음과 같이 이해할 수 있습니다.

```text
변수
 ↓
참조값
 ↓
객체
```

### `x = 10`

```text
x ─────▶ 0x0 ─────▶ [10]
```

### `y = x`

```text
x ─────▶ 0x0 ─────▶ [10]
y ─────▶ 0x0 ─────▶ [10]
```

### `x = 30`

```text
x ─────▶ 0x1 ─────▶ [30]
y ─────▶ 0x0 ─────▶ [10]
```

### `y = x`

```text
x ─────▶ 0x1 ─────▶ [30]
y ─────▶ 0x1 ─────▶ [30]
```

---

## 한 문장으로 정리

> **Python에서 `y = x`는 그 순간 `x`가 가지고 있는 참조값을 `y`에 복사하는 것이다.**

따라서 `x`가 다른 객체를 가리키도록 변경되어도 `y`의 참조값은 자동으로 변경되지 않습니다.

반대로 `append()`처럼 **객체 자체를 변경하는 경우에는 같은 객체를 가리키고 있는 다른 변수에서도 변경된 결과가 나타날 수 있습니다.**
